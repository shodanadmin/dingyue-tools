## 📦 下载与导入检查清单

- [ ] 确认下载页面属于表中开发者官网或项目 Releases。
- [ ] 在 Releases 选择适合自己的发布版本，新手优先选择正式版。
- [ ] 打开 **Assets**，选择设备对应的软件包；`Source code` 是源码，不是安装包。
- [ ] 核对系统和架构：Windows 常见 x64 / ARM64，Mac 区分 Intel / Apple Silicon，Android 按设备选择 APK。
- [ ] 导入对应客户端的订阅或配置，查看是否成功加载节点与规则。
- [ ] 按需求启用系统代理或 TUN / VPN 模式，避免多个客户端同时接管流量。
- [ ] 测试实际网页访问，检查日志与分流结果，再设置订阅自动更新。

## 💬 常见问题

<details>
<summary><strong>为什么能导入节点，却提示配置错误？</strong></summary>

节点信息、完整配置、规则集是不同内容。Clash / Mihomo 的 YAML、sing-box 的 JSON，以及 Surge / Quantumult X / Loon 的配置不能直接等同。先使用服务端提供的客户端专用订阅，再检查客户端与内核版本。

</details>

<details>
<summary><strong>系统代理和 TUN / VPN 模式怎么选？</strong></summary>

系统代理主要作用于遵循系统代理设置的应用；TUN / VPN 模式通过虚拟网络接口处理流量，覆盖范围由路由和分流设置决定。如果浏览器可用、其他应用不可用，可检查应用代理设置或 TUN 配置。

</details>

<details>
<summary><strong>延迟正常，但网页打不开，怎么办？</strong></summary>

依次检查订阅是否过期、节点是否可用、系统代理或 VPN 是否启用，再检查 DNS、分流规则与连接日志。延迟测试通过不代表目标网站一定能访问。

</details>

<details>
<summary><strong>为什么不继续推荐旧版 NekoRay、Clash for Windows 汉化包？</strong></summary>

[NekoRay 原项目](https://github.com/MatsuriDayo/nekoray)已归档，并明确说明不再维护，可查看 Throne 等桌面替代选项。原稿中的第三方汉化包和来源不明的旧版下载入口不符合本目录的官方来源要求，因此不继续收录。NekoBox for Android 是独立项目，不应与桌面 NekoRay 混为一谈。

</details>

<details>
<summary><strong>哪个协议最快？开源客户端就一定安全吗？</strong></summary>

没有适用于所有网络的最快协议。先确认服务端与客户端共同支持，再根据实际网络测试。开源代表代码可以公开检查，不代表本文审计过全部代码，也不构成安全保证；本目录同样收录了明确标注费用的商业工具。

</details>
